# learn-fullstack

learn-fullstack is a project-based TypeScript curriculum I built from language and web fundamentals through two production-style capstones: a Trello-like Kanban system and a realtime chat application. More than fifty modules and deep dives cover TypeScript, modern JavaScript, HTTP, Node.js, React, CSS/layout, animation, responsive design, internationalization, hooks, rendering and performance, forms, Suspense, Three.js, Storybook, accessibility, Redux Toolkit, Zustand, TanStack tools, SQL/PostgreSQL, Prisma, Express, NestJS, REST, GraphQL, authentication, WebSockets, uploads, background work, Next.js, Server Actions, testing, Docker/CI, supply-chain security, observability, profiling, and microfrontends. Shared packages, testing infrastructure, runnable exercises, and “from scratch” modules make architectural tradeoffs executable rather than purely theoretical.

## Technologies used

- **Frontend:** TypeScript, React 19, Next.js, Vite, Tailwind CSS, Storybook, Three.js/React Three Fiber, Framer Motion.
- **State and data fetching:** Redux Toolkit, Zustand, TanStack Query/Form/Table, React Hook Form, Zod.
- **Backend and APIs:** Node.js, Express, NestJS, REST, GraphQL, Apollo Server, Socket.IO/WebSockets.
- **Data and auth:** PostgreSQL, Prisma, raw pg, SQLite adapters, JOSE, sessions and password hashing.
- **Testing:** Vitest, React Testing Library, MSW, Supertest, Playwright, axe-core, Testcontainers.
- **Platform and delivery:** Turborepo, pnpm, tsup, SWC, Docker, CI/CD, observability and supply-chain tooling.

## Engineering evidence

The curriculum demonstrates broad full-stack command, teaching-oriented decomposition, comparative implementations, shared-package architecture, and production concerns carried into runnable capstones.
